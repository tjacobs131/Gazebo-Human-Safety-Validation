# Use Cases
The table below shows the use cases for the Alpha Ceres related to human actors in the area of operation. The cases themselves cover the main behaviors of people related to the Alpha Ceres. They do not explicitly include all the combinations of behaviors people can display in the simulation. The simulation allows for six different reactions to them being in vicinity of the Alpha Ceres. Each of them will be tested for each of the use cases. The descriptions of the reactions are available here: https://github.com/robotics-upo/hunav_sim?tab=readme-ov-file#features<br><br>

| Use Case ID | Description | Actors | Preconditions | Postconditions | Flow |
|-------------|-------------|-------|--------------|---------------|-------------|
| UC-1 | Alpha Ceres runs into stationary person | Alpha Ceres<br><br> Person | Alpha Ceres is moving.<br><br> Person is standing in front of Alpha Ceres | Alpha Ceres stops a comfortable distance from person.<br><br> Alpha Ceres moves safely around person | 1. Alpha Ceres detects person<br> 2. Alpha Ceres slows down<br> 3. Alpha Ceres calculates new route<br> 4a. Alpha Ceres finds a new route<br> 5a. Alpha Ceres uses new route to drive safely around the person<br> 4b. Alpha Ceres does not find a new route<br> 5b. Alpha Ceres waits for the person to move away from the route|
| UC-2 | Person crosses the path of Alpha Ceres | Alpha Ceres<br><br> Person | Alpha Ceres is moving. <br><br> Person is moving perpundicular to Alpha Ceres' path | Person crosses Alpha Ceres' path without discomfort. | 1. Alpha Ceres detects person<br> 2. Alpha Ceres stops a comfortable distance from person<br> 3. Alpha Ceres waits for person to cross<br> 4. Alpha Ceres starts moving when person has crossed |
| UC-3 | Alpha Ceres overtakes person | Alpha Ceres<br><br> Person | Alpha Ceres is moving<br><br> Person is moving in the same direction, in front of the Alpha Ceres | Alpha Ceres safely moves around person<br><br> Alpha Ceres slowly drives a safe distance behind person | 1. Alpha Ceres detects slower moving person<br> 2. Alpha Ceres calculates route around person<br> 3a. Alpha Ceres finds safe route<br> 4a. Alpha Ceres follows new route around person<br> 3b. Alpha Ceres does not find a comfortable path<br> 4b. Alpha Ceres slows down to the person's speed<br> 5b. Alpha Ceres stays behind person |
| UC-4 | Person overtakes Alpha Ceres | Alpha Ceres<br><br> Person | Alpha Ceres is moving forwards<br><br> Person is moving faster than the Alpha Ceres in the same direction | Person moves past Alpha Ceres without discomfort | 1. Person starts overtaking Alpha Ceres<br> 2. Alpha Ceres keeps moving predictably<br> 3. Person moves past Alpha Ceres |
